# 所得税いくら？（shotokuzei-ikura）

課税される所得金額（会社員のCさん 280万円・会社役員のVさん 2,500万円 など）を読んで、所得税の額を当てる1日5問の学習ゲーム。正解したら「税率は何％？」（5％〜45％の7つ）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/shotokuzei-ikura/>

- 答えは、国税庁タックスアンサー No.2260「所得税の税率」の速算表（課税される所得金額×税率−控除額。1,000円未満の端数は切り捨て）から計算しています（［令和8年4月1日現在法令等］。2026-11-17 に読みました）。
  - <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm>
- 所得控除の計算・復興特別所得税・防衛特別所得税・分離課税・とても所得の多い人の調整は出しません。人と金額はつくりものです。
- このゲームは所得税のしくみを知る練習です。税の相談の代わりではありません。実際の税額は、国税庁の資料や税務署で確かめてください。
